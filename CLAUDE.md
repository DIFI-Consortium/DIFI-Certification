# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Purpose

Tooling from the [DIFI Consortium](https://dificonsortium.org/) for verifying and validating DIFI (Digital IF Interoperability, IEEE-ISTO 4900-2021) packet streams — a VITA 49.2 schema used to carry IQ samples and metadata over UDP, primarily between satellite ground-station digitizers and software modems. Targets Linux (Ubuntu 24, including WSL).

## Architecture

Two top-level certification scripts, both consuming the same packet definitions:

- [certify_source.py](certify_source.py) — "certify a source" means: read DIFI packets (from pcap or live UDP) and validate them. UDP mode first dumps raw datagrams into a synthetic pcap (`temp.pcap`) using a hand-written global header, then re-uses the pcap path. Walks each packet, dispatches by `pktType` nibble (0x4 context, 0x1 data, 0x5 version), runs the per-type `validate()` from `packet_definitions/`, and tracks cross-packet invariants (sequence-number gaps mod 16, monotonic timestamps, stable stream ID, stable data-packet size).

- [certify_sink.py](certify_sink.py) — "certify a sink" means: act as a DIFI source and transmit packets so an external sink/receiver can be tested. Three threads send context (10/sec), version (2/sec), and data (rate-limited by `samples_per_packet/sample_rate`) packets to a UDP destination. Data payload is a tiled PN11 QPSK signal generated by `packet_definitions/pn11.py`. Bit-depth packing for 4/8/12/16-bit signed IQ is done inline; **endianness is big-endian** (network byte order) and 4-bit/12-bit modes do their own bit-packing.

Packet-definition layer ([packet_definitions/](packet_definitions/)):

- Uses the [Construct](https://construct.readthedocs.io/) library. Each `difi_<type>_v<ver>.py` file declares a `Struct(...)` named e.g. `difi_context_definition` and monkey-patches a `validate(packet)` function onto it (`difi_context_definition.validate = validate`). Callers invoke `parse(bytes)`, `build(dict)`, and `validate(parsed)` uniformly.
- For information about the different versions of DIFI, including the specs, see .claude/skills/difi.
- Scaled fixed-point fields (frequency, bandwidth, ref level, gain) go through `ExprAdapter` helpers in [construct_custom_types.py](packet_definitions/construct_custom_types.py) (Q-format with 2^20 or 2^7 scaling). When constructing dicts to `build()`, use the human-readable float; when reading from `parse()`, the result is already scaled.

Other components:

- [difi_to_binary_iq.py](difi_to_binary_iq.py) — standalone helper to extract raw IQ from a pcap into `.cs8`. Uses `pylibpcap` (not in `requirements.txt`); install separately if needed.
- [wireshark-dissector/](wireshark-dissector/) — independent Lua plugin (no Python coupling); copy `difi-dissector.lua` to the user's Wireshark plugins directory.
- [example_pcaps/](example_pcaps/) — reference captures used by docs and CI; do not modify.

## Common commands

Setup:
```bash
python -m venv difi-venv && . difi-venv/bin/activate
pip install -r requirements.txt
```

Parse/validate a DIFI stream (pcap or live UDP):
```bash
python certify_source.py --pcap example_pcaps/Example1_1Msps_8bits.pcapng
python certify_source.py --udp-port 50003                 # records via tcpdump-style loop until Ctrl-C
python certify_source.py --config certify_source_example_config.yml
python certify_source.py --pcap <file> --pn11             # also runs PN11 QPSK BER demod
```

Generate a DIFI UDP stream:
```bash
python certify_sink.py --duration 10 --port 50003 --sample-rate 100e3 --packet-size small --bit-depth 8
# capture it in parallel with: sudo tcpdump -i lo udp port 50003 -w output.pcap
```

Format packet-definition files: `ruff format --line-length=160 <file>.py` (per [packet_definitions/README.md](packet_definitions/README.md)).

Tests live only in CI ([.github/workflows/install_and_test.yml](.github/workflows/install_and_test.yml)) — there is no local test runner. To reproduce a CI step locally, run the same command from that workflow.
